# Plan: Tách 2 luồng Move — Normal vs Turbo Chunk

## Vấn đề

Hiện tại `executeMove` (line 1588) chỉ xử lý **normal move** (MoveQueue: `tmp → .i10r → .ipsw`). Logic turbo chunk move (progressive IOWriteQueue: `tmp chunks → .turbo → .i10r → .ipsw`) nằm inline trong `runDownload` step 9 (lines 1102-1164), không được extract ra.

Hậu quả:
- Recovery paths (`runMoveOnly`, `runVerifyAndMove`) chỉ gọi `executeMove` → không recover được turbo chunk move
- `executeMove` không check `.turbo` file từ lần move bị interrupt
- Code trùng lặp giữa step 9 inline và recovery path

## Giải pháp

Tách thành 2 method riêng biệt, `executeMove` trở thành dispatcher.

### 1. `executeNormalMove(id, task, state)` — Normal flow

Move toàn bộ file qua MoveQueue:
```
tmp → .ipsw.i10r (via MoveQueue) → rename → .ipsw
```

Logic tương tự `executeMove` hiện tại. Check `.i10r` tồn tại từ lần move bị interrupt → skip move, chỉ rename.

### 2. `executeTurboChunkMove(id, task, state, cm?)` — Turbo chunk flow

Hoàn tất progressive move qua IOWriteQueue:
```
drain remaining chunks → .turbo → rename → .i10r → rename → .ipsw
```

**Tham số `cm` (ChunkManager)**: Chỉ có khi gọi từ `runDownload` step 9 (ChunkManager đang active). Khi recovery (`cm` = undefined), check `.turbo` file + `movedChunks` completeness.

Logic extract từ `runDownload` step 9 lines 1102-1164:

**Khi có `cm` (normal operation):**
1. Set status "moving", progress từ `cm.getTotalMovedBytes()`
2. `cm.drainIOWorker()` — đợi tất cả queued chunks hoàn thành
3. Verify `movedChunks` completeness
4. Nếu all moved + drain OK: rename `.turbo → .i10r → .ipsw`
5. Nếu incomplete: cleanup `.turbo`, fallback `executeNormalMove`

**Khi không có `cm` (recovery):**
1. Check `.turbo` file tồn tại
2. Nếu `.turbo` exists + all chunks moved: rename `.turbo → .i10r → .ipsw`
3. Nếu `.turbo` exists + incomplete: cleanup `.turbo`, fallback `executeNormalMove`
4. Nếu `.turbo` không tồn tại: fallback `executeNormalMove`

### 3. `executeMove` → dispatcher

private async executeMove(id, task, state): Promise<void> {

## Chi tiết implementation

### `executeNormalMove` (rename từ executeMove hiện tại)

```typescript
private async executeNormalMove(id: string, task: Task, state: DownloadState): Promise<void> {
  const isHDD = !(await this.diskManager.detectSSD(task.savePath));
  const finalPath = this.buildFinalPath(task.firmware, task.savePath);
  const i10rPath = this.buildI10rPath(task.firmware, task.savePath);

  this.updateTaskStatus(id, "moving");
  state.activeOperation = "move";
  this.doCheckpoint(id);

  task.progress = 0;
  task.speed = 0;
  task.eta = undefined;
  this.emitProgressNow(id, task);

  if (fs.existsSync(i10rPath)) {
    try { fs.unlinkSync(finalPath); } catch {}
    fs.renameSync(i10rPath, finalPath);
  } else {
    const isTurbo = task.mode === "turbo";
    await this.moveQueue.enqueue(state.tmpPath, i10rPath, isHDD, isTurbo, ({ pct, speed, eta }) => {
      task.progress = pct;
      task.speed = speed;
      task.eta = eta;
      this.emitThrottledProgress(id, task);
    });
    try { fs.unlinkSync(finalPath); } catch {}
    fs.renameSync(i10rPath, finalPath);
  }

  task.progress = 100;
  task.speed = 0;
  task.eta = 0;
  this.updateTaskStatus(id, "completed");
  this.emitProgressNow(id, task);
  this.emit("completed", id, task);
  this.cleanupCheckpoint(id);
  this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: true, deleteStateFile: true, deleteTask: false });
}
```

### `executeTurboChunkMove` (extract từ step 9 turbo path)

```typescript
private async executeTurboChunkMove(
  id: string,
  task: Task,
  state: DownloadState,
  cm?: ChunkManager,
): Promise<void> {
  const finalPath = this.buildFinalPath(task.firmware, task.savePath);
  const i10rPath = this.buildI10rPath(task.firmware, task.savePath);
  const turboPath = this.buildTurboPath(task.firmware, task.savePath);

  this.updateTaskStatus(id, "moving");
  state.activeOperation = "move";
  this.doCheckpoint(id);

  if (cm) {
    // ── Normal operation: ChunkManager đang active ──
    const initialMoved = cm.getTotalMovedBytes();
    task.progress = state.totalSize > 0 ? (initialMoved / state.totalSize) * 100 : 0;
    task.speed = 0;
    task.eta = undefined;
    this.emitProgressNow(id, task);

    let drainFailed = false;
    try {
      await cm.drainIOWorker();
    } catch (drainErr: any) {
      console.error(`[IPSWDownloader] drainIOWorker failed for ${id}:`, drainErr.message);
      drainFailed = true;
      cm.stopIOWorker().catch(() => {});
    }

    const totalMoved = cm.getTotalMovedBytes();
    task.progress = state.totalSize > 0 ? Math.min(99, (totalMoved / state.totalSize) * 100) : 100;
    this.emitThrottledProgress(id, task);

    const stateReloaded = this.stateManager.load(id);
    const completedIndices = (stateReloaded?.chunks ?? []).filter(c => c.completed).map(c => c.index);
    const movedSet = new Set(stateReloaded?.movedChunks ?? []);
    const allMoved = completedIndices.every(i => movedSet.has(i));

    if (allMoved && !drainFailed) {
      try { fs.unlinkSync(i10rPath); } catch {}
      fs.renameSync(turboPath, i10rPath);
      try { fs.unlinkSync(finalPath); } catch {}
      fs.renameSync(i10rPath, finalPath);
    } else {
      cm.cleanupTurboFile();
      this.emit("log", id, `Turbo move incomplete (${movedSet.size}/${completedIndices.length} chunks), falling back to MoveQueue`);
      return this.executeNormalMove(id, task, state);
    }
  } else {
    // ── Recovery: ChunkManager không active ──
    task.progress = 0;
    task.speed = 0;
    task.eta = undefined;
    this.emitProgressNow(id, task);

    if (fs.existsSync(turboPath)) {
      const stateReloaded = this.stateManager.load(id);
      const completedIndices = (stateReloaded?.chunks ?? []).filter(c => c.completed).map(c => c.index);
      const movedSet = new Set(stateReloaded?.movedChunks ?? []);
      const allMoved = completedIndices.every(i => movedSet.has(i));

      if (allMoved) {
        try { fs.unlinkSync(i10rPath); } catch {}
        fs.renameSync(turboPath, i10rPath);
        try { fs.unlinkSync(finalPath); } catch {}
        fs.renameSync(i10rPath, finalPath);
      } else {
        try { fs.unlinkSync(turboPath); } catch {}
        return this.executeNormalMove(id, task, state);
      }
    } else {
      return this.executeNormalMove(id, task, state);
    }
  }

  task.progress = 100;
  task.speed = 0;
  task.eta = 0;
  this.updateTaskStatus(id, "completed");
  this.emitProgressNow(id, task);
  this.emit("completed", id, task);
  this.cleanupCheckpoint(id);
  this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: true, deleteStateFile: true, deleteTask: false });
}
```

### `executeMove` dispatcher

```typescript
private async executeMove(id: string, task: Task, state: DownloadState): Promise<void> {
  const turboPath = this.buildTurboPath(task.firmware, task.savePath);
  if (fs.existsSync(turboPath)) {
    return this.executeTurboChunkMove(id, task, state);
  }
  return this.executeNormalMove(id, task, state);
}
```
