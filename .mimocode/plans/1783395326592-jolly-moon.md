# Plan: Downloader Overhaul — Recovery, Checkpoint Safety, Stream Verify

## Overview
Triển khai 6 thay đổi chính cho `electron/modules/downloader/`:
1. Progress trả số nguyên (không làm tròn trong backend)
2. Thêm `lastCheckpoint`, `lastWriteTime`, `activeOperation` vào DownloadState
3. Cơ chế recovery thay thế incompleteTask
4. i10r file convention (`.ipsw.i10r`, `.json.i10r`)
5. Checkpoint timing an toàn (task_pause, app_exit, 30s, 10 chunks)
6. Stream verify (hash during download/move)

## 3. i10r File Convention

### 3a. `.ipsw.i10r` cho file đang move

**Quyết định**: Giữ nguyên `.ipsw.tmp` cho file download trong tmp dir. Chỉ dùng `.ipsw.i10r` ở **savePath** khi đang move.

**Thay đổi trong `downloader.ts`**:
- File download vẫn là `${id}.ipsw.tmp` trong tmp dir (không đổi)
- Khi bắt đầu move (step 9): move tmp → `{savePath}/{filename}.ipsw.i10r`
- Khi move hoàn tất: rename `.ipsw.i10r` → `.ipsw` (final path)
- Khi cancel/error trong move phase: xóa `.ipsw.i10r` ở savePath

**Thay đổi trong recovery**:
- Khi `activeOperation === "move"`: kiểm tra `.ipsw.i10r` ở savePath còn không
- Nếu `.ipsw.i10r` còn → move lại (rename → `.ipsw`)
- Nếu `.ipsw.i10r` mất nhưng tmp còn → move lại từ đầu
- Nếu cả hai mất → xóa state

**Lợi ích**: File `.ipsw.i10r` ở savePath không bị nhầm với file IPSW thật. Nếu app crash giữa move, file không bị corrupt.

**Helper mới trong `downloader.ts`**:
```typescript
private buildI10rPath(firmware: Firmware, savePath: string): string {
  const filename = this.extractFilename(firmware);
  const dir = fs.existsSync(savePath) && fs.statSync(savePath).isDirectory()
    ? savePath
    : path.dirname(savePath);
  return path.join(dir, `${filename}.i10r`);
}
```

**`cleanupRuntime`** — Thêm cleanup `.ipsw.i10r`:
```typescript
// Clean up .ipsw.i10r at savePath if exists
const i10rPath = this.buildI10rPath(state.firmware, state.savePath);
if (fs.existsSync(i10rPath)) {
  try { fs.unlinkSync(i10rPath); } catch {}
}
```

**Cập nhật `runDownload` step 9**: Thay vì move trực tiếp sang final path, giờ move sang `.ipsw.i10r` rồi rename.

**Files**: `downloader.ts`

## 4. Checkpoint Timing

**Vấn đề**: Hiện tại ghi state sau mỗi chunk hoàn thành (2s debounce trong ChunkManager). Không an toàn nếu crash giữa write.

**Thay đổi**:
- **Bỏ** `queueStateUpdate` / `flushStateNow` debounce trong `chunk-manager.ts`
- **Thay bằng** checkpoint logic trong `downloader.ts`:

**Điều kiện trigger checkpoint** (OR):
1. `task_pause` — Ghi state ngay khi pause
2. `app_exit` — Ghi state khi destroy (đã có, đảm bảo atomic)
3. `every 30 seconds` — Timer reset khi checkpoint xảy ra
4. `every 10 chunks hoàn thành` — Đếm chunks, reset khi checkpoint xảy ra

**Triển khai trong `downloader.ts`**:
```typescript
private checkpointState = new Map<string, {
  timer: NodeJS.Timeout | null;
  completedChunks: number;  // đếm từ lần checkpoint cuối
  lastCheckpointAt: number;
}>();

private scheduleCheckpoint(id: string): void {
  const cs = this.checkpointState.get(id);
  if (!cs) return;
  cs.completedChunks++;
  
  // 10 chunks hoặc 30s timer
  if (cs.completedChunks >= 10) {
    this.doCheckpoint(id);
  } else if (!cs.timer) {
    cs.timer = setTimeout(() => this.doCheckpoint(id), 30_000);
  }
}

private doCheckpoint(id: string): void {
  const cs = this.checkpointState.get(id);
  if (cs?.timer) { clearTimeout(cs.timer); cs.timer = null; }
  cs.completedChunks = 0;
  cs.lastCheckpointAt = Date.now();
  
  const state = this.states.get(id);
  if (state) {
    const { lastCheckpoint, lastWriteTime } = this.stateManager.saveAtomic(state);
    state.lastCheckpoint = lastCheckpoint;
    state.lastWriteTime = lastWriteTime;
  }
}
```

**Tích hợp**:
- `chunkComplete` event → `scheduleCheckpoint(id)`
- `pause()` → `doCheckpoint(id)` (trước khi emit paused)
- `cancel()` → xóa state luôn (không cần checkpoint)
- `runDownload` step 8 (verify start) → `doCheckpoint(id)` + set `activeOperation = "verify"`
- `runDownload` step 9 (move start) → `doCheckpoint(id)` + set `activeOperation = "move"`
- `destroy` handler → `doCheckpoint(id)` cho tất cả tasks

**Files**: `downloader.ts`, `state-manager.ts`

## 5. Recovery Mechanism

### 5a. Loại bỏ `incompleteTask` concept

**Hiện tại**: `getIncompleteTasks()` scan state files, renderer hiển thị card riêng.

**Mới**: State files chính là source of truth. **Recovery chạy tự động khi worker boot**.

**Flow**:
1. Worker boot → gọi `recoverOnStartup()` trong constructor
2. Scan tất cả `{id}.json` trong state dir
3. Kiểm tra tính hợp lệ:
   - Nếu `activeOperation === "download"`: kiểm tra `.ipsw.tmp` còn không
   - Nếu `activeOperation === "verify"`: `.ipsw.tmp` phải còn, bắt đầu verify lại
   - Nếu `activeOperation === "move"`: kiểm tra `.ipsw.i10r` ở savePath hoặc `.ipsw.tmp` trong tmp dir
4. Chuyển thành Task với status dựa trên `config.autoResume`:
   - `true` (default) → status `"queued"`, enqueue theo activeOperation
   - `false` → status `"paused"`, user gọi `resume(task_id)` để tiếp tục
5. Emit `added` event cho mỗi task recovered → renderer nhận qua `dm:added`

### 5b. Thêm `auto_resume` config

**`types.ts`** — Thêm vào `DownloaderConfig`:
```typescript
autoResume?: boolean;  // default: true
```

**`global.d.ts`** — Đồng bộ.

### 5c. Recovery flow trong `downloader.ts`

Thêm method mới:
```typescript
async recoverOnStartup(): Promise<void> {
  const states = await this.stateManager.listAll();
  
  for (const state of states) {
    if (this.tasks.has(state.id)) continue; // already active
    
    const tmpExists = !!(state.tmpPath && fs.existsSync(state.tmpPath));
    const i10rPath = this.buildI10rPath(state.firmware, state.savePath);
    const i10rExists = fs.existsSync(i10rPath);
    
    // ── Validate based on activeOperation ──
    if (state.activeOperation === "download" && !tmpExists) {
      // Tmp mất — reset chunks, vẫn recover
      for (const c of state.chunks) { c.downloaded = 0; c.completed = false; }
      state.movedChunks = [];
      this.stateManager.save(state);
    }
    
    if (state.activeOperation === "verify" && !tmpExists) {
      // Tmp mất khi đang verify — không thể tiếp tục
      this.stateManager.delete(state.id);
      continue;
    }
    
    if (state.activeOperation === "move" && !tmpExists && !i10rExists) {
      // Cả tmp và i10r đều mất — không thể tiếp tục
      this.stateManager.delete(state.id);
      continue;
    }
    
    // ── Tạo Task ──
    const downloadedBytes = state.chunks.reduce((s, c) => s + c.downloaded, 0);
    const task: Task = {
      id: state.id,
      firmware: state.firmware,
      progress: state.totalSize > 0 ? downloadedBytes / state.totalSize * 100 : 0,
      speed: 0,
      status: this.config.autoResume !== false ? "queued" : "paused",
      savePath: state.savePath,
      mode: state.mode ?? "normal",
    };
    
    this.tasks.set(state.id, task);
    this.states.set(state.id, state);
    this.diskManager.reserveSpace(state.id, state.firmware.filesize);
    
    // ── Enqueue based on autoResume ──
    if (this.config.autoResume !== false) {
      const wasTurbo = this.validateTurboForRecovery(state);
      
      if (state.activeOperation === "verify") {
        this.scheduler.enqueue({
          id: state.id,
          turboPriority: false,
          run: () => this.runVerifyAndMove(state.id),
        });
      } else if (state.activeOperation === "move") {
        this.scheduler.enqueue({
          id: state.id,
          turboPriority: false,
          run: () => this.runMoveOnly(state.id),
        });
      } else {
        this.scheduler.enqueue({
          id: state.id,
          turboPriority: wasTurbo,
          run: () => this.runDownload(state.id),
          onSlotOpen: (slotType: DownloadMode) => {
            const t = this.tasks.get(state.id);
            if (t) { t.mode = slotType; this.emit("progress", state.id, t); }
          },
        });
      }
    }
    
    this.emit("added", state.id, task);
  }
}
```

### 5d. Thêm `runVerifyAndMove` và `runMoveOnly`

```typescript
private async runVerifyAndMove(id: string): Promise<void> {
  const task = this.tasks.get(id);
  const state = this.states.get(id);
  if (!task || !state) return;
  
  const gen = (this.runGenerations.get(id) ?? 0) + 1;
  this.runGenerations.set(id, gen);
  
  try {
    // ── Verify (từ runDownload step 8) ──
    this.updateTaskStatus(id, "verifying");
    state.activeOperation = "verify";
    task.speed = 0;
    task.eta = undefined;
    this.emitProgressNow(id, task);
    
    if (!this.config.skipVerify) {
      const result = await this.integrity.verify(state.tmpPath, task.firmware, ({ pct, speed, eta }) => {
        task.progress = pct;
        task.speed = speed;
        task.eta = eta;
        this.emitThrottledProgress(id, task);
      });
      
      if (!result.ok) {
        this.updateTaskStatus(id, "error");
        task.error = `Checksum mismatch (${result.algo}): expected ${result.expected}, got ${result.actual}`;
        this.emit("error", id, task.error, task);
        this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: true, deleteStateFile: true, deleteTask: true });
        return;
      }
    }
    
    // ── Move (từ runDownload step 9) ──
    await this.executeMove(id, task, state);
    
  } catch (err: any) {
    if (this.runGenerations.get(id) !== gen) return;
    this.updateTaskStatus(id, "error");
    task.error = err.message;
    this.emit("error", id, err.message, task);
    this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: false, deleteStateFile: false, deleteTask: true });
  }
}

private async runMoveOnly(id: string): Promise<void> {
  const task = this.tasks.get(id);
  const state = this.states.get(id);
  if (!task || !state) return;
  
  const gen = (this.runGenerations.get(id) ?? 0) + 1;
  this.runGenerations.set(id, gen);
  
  try {
    await this.executeMove(id, task, state);
  } catch (err: any) {
    if (this.runGenerations.get(id) !== gen) return;
    this.updateTaskStatus(id, "error");
    task.error = err.message;
    this.emit("error", id, err.message, task);
    this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: false, deleteStateFile: false, deleteTask: true });
  }
}

/** Shared move logic extracted from runDownload step 9 */
private async executeMove(id: string, task: Task, state: DownloadState): Promise<void> {
  const isHDD = !(await this.diskManager.detectSSD(task.savePath));
  const finalPath = this.buildFinalPath(task.firmware, task.savePath);
  const i10rPath = this.buildI10rPath(task.firmware, task.savePath);
  
  this.updateTaskStatus(id, "move");
  state.activeOperation = "move";
  this.doCheckpoint(id);
  
  task.progress = 0;
  task.speed = 0;
  task.eta = undefined;
  this.emitProgressNow(id, task);
  
  // Move tmp → .ipsw.i10r (atomic at destination)
  const isTurbo = task.mode === "turbo";
  await this.moveQueue.enqueue(state.tmpPath, i10rPath, isHDD, isTurbo, ({ pct, speed, eta }) => {
    task.progress = pct;
    task.speed = speed;
    task.eta = eta;
    this.emitThrottledProgress(id, task);
  });
  
  // Rename .ipsw.i10r → .ipsw
  try { fs.unlinkSync(finalPath); } catch {}
  fs.renameSync(i10rPath, finalPath);
  
  // Done
  task.progress = 100;
  task.speed = 0;
  task.eta = 0;
  this.updateTaskStatus(id, "completed");
  this.emitProgressNow(id, task);
  this.emit("completed", id, task);
  this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: true, deleteStateFile: true, deleteTask: false });
}
```

## 6. Stream Verify

**Vấn đề**: Hiện tại verify xảy ra SAU khi download hoàn tất. Nếu file hỏng, phải tải lại.

**Giải pháp**: Tính hash song song trong quá trình download bằng Node.js `crypto` module.

**Quyết định**: Native Rust hash chỉ dành cho user manual verify (kiểm tra file đã tải trước đó). Stream verify tự implement bằng Node.js.

### 6a. Architecture

**Tạo file mới: `stream-hash.ts`** — Incremental hash wrapper:
```typescript
import crypto from "crypto";

type HashAlgo = "md5" | "sha1" | "sha256";

export class StreamHasher {
  private hash: crypto.Hash;
  private algo: HashAlgo;
  private bytesHashed = 0;
  
  constructor(algo: HashAlgo) {
    this.algo = algo;
    this.hash = crypto.createHash(algo);
  }
  
  /** Feed data vào hasher (gọi từ flushBuffers trong chunk-manager) */
  update(data: Buffer): void {
    this.hash.update(data);
    this.bytesHashed += data.length;
  }
  
  /** Finalize và trả về hex digest */
  finalize(): string {
    return this.hash.digest("hex");
  }
  
  getBytesHashed(): number {
    return this.bytesHashed;
  }
  
  getAlgo(): HashAlgo {
    return this.algo;
  }
}
```

### 6c. Tích hợp vào Downloader

**`downloader.ts`** — Trong `runDownload()`:
```typescript
// Step 5.5: Tạo StreamHasher (trước khi download)
let streamHasher: StreamHasher | undefined;
if (!this.config.skipVerify) {
  // Chọn algo ưu tiên: md5 → sha1 → sha256
  const algo = task.firmware.md5sum ? "md5"
    : task.firmware.sha1sum ? "sha1"
    : task.firmware.sha256sum ? "sha256"
    : undefined;
  if (algo) streamHasher = new StreamHasher(algo);
}

// Truyền streamHasher vào ChunkManager options
const cm = new ChunkManager(state, this.stateManager, {
  // ... existing options ...
  streamHasher,
});

// Step 8: Verify
if (!this.config.skipVerify) {
  if (streamHasher) {
    // Stream hash đã tính xong trong quá trình download
    const computed = streamHasher.finalize();
    const expected = streamHasher.getAlgo() === "md5" ? task.firmware.md5sum
      : streamHasher.getAlgo() === "sha1" ? task.firmware.sha1sum
      : task.firmware.sha256sum;
    
    if (computed.toLowerCase() !== expected.toLowerCase()) {
      // Hash mismatch — báo lỗi
      this.updateTaskStatus(id, "error");
      task.error = `Checksum mismatch (${streamHasher.getAlgo()}): expected ${expected}, got ${computed}`;
      this.emit("error", id, task.error, task);
      this.cleanupRuntime(id, { releaseSpace: true, deleteTmpFile: true, deleteStateFile: true, deleteTask: true });
      return;
    }
    // Hash OK — skip native verify
  } else {
    // Không có hash info — fallback verify bằng native (user-initiated)
    // Hoặc skip nếu không có hash
  }
}
```

### 6d. Lợi ích

- **Không cần native module support** — dùng Node.js crypto có sẵn
- **Hash trong khi download** — không cần đọc file lại sau download
- **CPU overhead thấp** — crypto hash rất nhanh (MD5 ~500MB/s, SHA256 ~300MB/s trên CPU hiện đại)
- **Native Rust hash** vẫn giữ nguyên cho user manual verify (không thay đổi `integrity.ts`)

**Files**: `stream-hash.ts` (mới), `chunk-manager.ts`, `downloader.ts`

## Verification

1. **Build**: `npm run build:main` — Kiểm tra TypeScript compile
2. **Manual test**:
   - Tải 1 file → pause giữa chừng → restart app → kiểm tra recovery (task xuất hiện trong UI)
   - Tải 1 file → force kill app giữa download → restart → kiểm tra recovery
   - Tải 1 file → force kill app giữa verify → restart → kiểm tra `activeOperation === "verify"` → verify lại tự động
   - Tải 1 file → force kill app giữa move → restart → kiểm tra `activeOperation === "move"` → move lại tự động
   - Kiểm tra `.json.i10r` file xuất hiện tạm thời khi ghi state (không nên còn sau khi ghi xong)
   - Kiểm tra `.ipsw.i10r` file ở savePath khi đang move (rename thành .ipsw khi xong)
   - Kiểm tra progress value là float (không phải integer)
   - Kiểm tra stream verify: download xong → verify bằng Node.js hash → skip native verify
3. **Edge cases**:
   - Tmp file bị xóa manual → recovery reset chunks (download phase)
   - `.ipsw.i10r` bị xóa manual → recovery move lại từ tmp (move phase)
   - State file bị corrupt → skip (đã có trong `listAll()`)
   - `auto_resume = false` → task recovered ở trạng thái paused
   - `config.skipVerify = true` → skip stream verify, không verify sau download
